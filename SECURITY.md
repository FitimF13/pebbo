# Security policy

Pebbo runs in people's homes and offices and handles voices, memories and smart home devices. Security reports are taken seriously.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) for this repository. Do not open a public issue.

Include what is affected, how to reproduce it and what an attacker could achieve. Use synthetic data only.

## Supported versions

Pebbo has not been released yet. Until the first release, only the `main` branch receives fixes.

## Scope

Especially relevant:

- Access to another person's memories, reminders, calendars or voice data
- Device actions or data exchange between instances without the required approval
- Pairing or relay weaknesses that expose a home Pebbo to the internet
- Any outbound connection that the owner did not enable
